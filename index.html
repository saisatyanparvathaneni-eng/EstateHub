Frequently asked questions

Honest answers make a better demo. EstateHub does not represent a live brokerage service.

See demo boundaries ↗
How can I search for properties?

Use the main search field or the filter panel. Search checks property names, locations, types, descriptions, and listed facilities. Filters can be combined.

Are the properties displayed here real?

No. All listings, names, prices, locations, and agent references are fictional demonstration data created for this frontend project.

Can I save and compare a property?

Yes. Favorites are stored in this browser's LocalStorage. Comparison supports up to three properties and labels sale prices separately from monthly rent.

Does EstateHub provide live availability or maps?

No. The location area is an illustrative placeholder. This project does not claim live traffic, inventory, coordinates, or nearby-facility verification.

Can I submit my own property listing?

You can prepare a clearly marked user-submitted demo listing in the form. It is added only to this browser session and is never published or verified.

Is the login connected to a backend?

No. Login and account creation are interface demonstrations only. Passwords are not stored and no account is created.

What information is stored in LocalStorage?

Theme preference, favorites, comparison IDs, modest UI preferences, and non-sensitive demo listings may be stored. Passwords and inquiry contents are not stored.
